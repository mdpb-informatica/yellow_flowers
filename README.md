# flores-amarillas

Experiencia 3D interactiva en React + Vite para celebrar el Día de las Flores Amarillas.

## Novedades de la versión 1.10.0

- meteoritos más realistas: cabeza luminosa adelante y estela detrás
- meteoritos automáticos de fondo que aparecen por instantes y desaparecen
- el texto principal tiene prioridad visual y puede pasar por encima de los textos secundarios
- inicio de cámara adaptable: zoom alejado en pantallas normales y zoom medio en pantallas compactas
- textos secundarios pequeños, en una sola línea y sin emojis pegados al texto
- sin cuadros ni fondos detrás de los textos
- bloqueo de selección para escritorio, Android y iPhone
- pantalla inicial con **Click**, sin botón visual

## Requisitos

- Node.js 20 o superior recomendado
- npm

## Ejecutar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```
